# Aplication Frontend (Demo)

Proyecto frontend demo para el sistema "Gestor Canchas".

Características:
- React + Vite
- Tailwind CSS
- Páginas: Login, Forgot Password, Profile, Update Profile
- No está conectado al backend; los formularios son simulados para diseño y flujo.

Cómo ejecutar:

1. Instalar dependencias:

```bash
cd aplication-fronted
npm install
```

2. Ejecutar en modo desarrollo:

```bash
npm run dev
```

3. Abrir la app en el navegador (por defecto `http://localhost:5173`).

Notas:
- Cuando el backend esté listo, las llamadas se conectarán a `http://localhost:3000/api`.
- Pueden cambiar la paleta en `tailwind.config.cjs` y los estilos en `src/index.css`.
